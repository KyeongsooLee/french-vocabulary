# TEF Vocab Loop — QA NOTES

## General QA strategy

Full GUI automation has not been reliable in the development environment for local HTML.

Primary QA methods:

- `node --check` for JavaScript syntax,
- embedded card-count checks,
- targeted logic tests,
- static HTML/JS assertions,
- custom engine simulations,
- real Android user testing for final UX.

Do not claim full browser end-to-end automation unless it has actually been performed.

## Regression checklist for future versions

Before shipping a new version, at minimum verify:

1. JS syntax passes.
2. Card count remains 2,866 unless an intentional data migration is documented.
3. Card IDs remain stable.
4. Existing progress storage still loads.
5. New words are not tested before introduction.
6. `확인했어요` only => Seen, not Learning.
7. Spelling still does not gate mastery.
8. Word audio does not speak grammar metadata.
9. Example audio still works.
10. Word audio controls remain outside the white example card.
11. Whole-topic study does not regress to source-order selection.
12. Previous-introduction replay does not mutate state.
13. Active session can resume.
14. Sentence Recommended/All modes still render.
15. Direct-open Android use remains viable.
