This file is a quick target map for the next content pass.

| Pattern | Count | Main category |
|---|---:|---|
| `Ce cours porte sur ...` | 34 | L’histoire |
| `Ce documentaire parle de/du ...` | 28 | L'environnement |
| `Le journal parle de/du ...` | 24 | Les actualités |

| `Le médecin parle de/du ...` | 32 | La santé |

**Total high-confidence batch: 144**

These are good candidates because the sentence frame is generic and usually teaches almost nothing about how the target word is actually used.

## Lower-confidence families

- `On parle souvent du ...` — 23 cards
- `On parle de ...` — 93 cards

Do **not** automatically rewrite all of these. Some may contain acceptable constructions.

## After template cleanup

Run a semantic pass over the full corpus and score examples by:

- real-life usefulness
- collocation value
- grammar/construction value
- TEF reuse value
- naturalness
- target meaning clarity
- redundancy with other examples
- sentence length/complexity

The goal is not to make every sentence difficult.  
The goal is to make each sentence teach something worth remembering.
